EMILIANO MAGAÑA — VERSION SIN CARPETAS PARA GITHUB PAGES

Esta versión coloca TODOS los archivos en la RAÍZ del repositorio.
NO mezcles este index.html con la versión antigua que usa /assets/.

1) Descarga y EXTRAE este ZIP (no subas el ZIP).
2) En el repositorio de GitHub, usa Add file > Upload files.
3) Selecciona TODOS los archivos de esta carpeta ya extraída; no la carpeta contenedora.
4) Comprueba en GitHub que index.html, marca.webp, presentacion-evento-01.mp4,
   presentacion-evento-02.mp4 y prueba-vocal.m4a aparezcan AL MISMO NIVEL.
5) Borra o ignora la carpeta assets vieja para evitar confusión.
6) Confirma Commit changes y revisa Settings > Pages: Deploy from a branch,
   rama correcta (normalmente main) y directorio / (root).
7) Haz una recarga Ctrl+F5 o abre una ventana privada.

Si todavía falla, abre directamente en tu dominio /marca.webp y
/presentacion-evento-01.mp4 para confirmar que GitHub publicó los archivos.
No se pudo verificar la configuración real de tu repositorio privado/remoto.
